Project Overview

Designed and implemented a data engineering and analytics solution for the client's internal financial reporting requirements, integrating Microsoft Dataverse and SharePoint-based Excel files as the primary data sources.

Architecture

Ingestion Layer

  • SharePoint Excel files: Ingested and transformed using Microsoft Fabric Dataflow Gen2, with processed data stored in the Fabric Lakehouse Bronze layer
  • Dataverse tables: Integrated using Fabric Link for near-real-time replication into the Fabric Lakehouse

Processing Layer

  • Databricks PySpark notebooks perform data transformation, cleansing, and business logic implementation
  • Data structures designed to support the Power BI semantic model

Orchestration

  • Microsoft Fabric Pipelines provide end-to-end orchestration and scheduled execution of all data workflows
  • Automated, scalable Lakehouse-based architecture for internal analytics
