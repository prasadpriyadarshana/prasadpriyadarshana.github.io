Phase 1 — Design V1: DirectQuery Optimisation

April 2023 to August 2024

Architecture

Designed and implemented a Power BI DirectQuery architecture for near-real-time reporting directly against the client's SQL Server data source. Since SQL Server was the client's primary system of record, the solution was architected to leverage the existing database rather than introducing an additional replication layer.

Optimisations Applied

  • Native SQL query optimisation: Replaced Power BI auto-generated queries with hand-crafted native SQL queries tuned for the specific reporting patterns
  • Indexing strategy: Implemented appropriate indexing across underlying tables to improve query execution and reduce database response times
  • Apply Slicer functionality: Implemented manual apply-filter controls across report pages, allowing users to configure multiple filters before triggering query execution — significantly reducing redundant DirectQuery requests

Results

  • ~150% improvement in Power BI query-loading performance from SQL optimisation
  • Further 150% improvement from Apply Slicer implementation reducing redundant queries

Phase 2 — Design V2: Multi-Region Lakehouse Architecture

September 2023 to Present

Problem

As business requirements expanded, the data landscape became geographically distributed across multiple regions, requiring a scalable architecture capable of consolidating regional data while maintaining data locality and performance. Microsoft Dataverse became the primary backend data source across three regions.

Architecture

  • Three regional Azure Synapse Analytics environments using Synapse Link for Dataverse to replicate regional data locally in near-real-time
  • Databricks PySpark used as the distributed processing engine for cross-region data transformations and standardisation
  • Unified data model: Lakehouse data model designed to consolidate all three regions into a unified table structure using a star-schema approach with a dedicated Region attribute for region-level filtering
  • Microsoft Fabric Lakehouses as the centralised storage and analytics layer

Results

  • £3,500/month saved by consolidating three separate regional Synapse/Dataverse environments into a single Databricks transformation layer
  • Single-pane visibility across all geographies for stakeholders for the first time
  • Both internal and external users can access and analyse data across multiple regions from a single platform
