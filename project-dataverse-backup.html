Dataverse Production-to-UAT Backup & Migration Solution

A selective, on-demand Dataverse data migration platform built on Databricks — eliminating full environment restores by allowing specific users and their associated data to be migrated from Production to UAT without disrupting downstream integrations.

Problem

The existing approach for populating the UAT environment with production data required a complete Production Dataverse environment restoration into UAT whenever production data was needed for development or testing. This caused:

  • Significant rework — full environment restore is destructive and time-consuming
  • Increased data volumes and storage costs — 30GB full restore when only specific records were needed
  • Disruptions to downstream applications, reporting synchronisations, and integrations
  • A 1-day manual restore process blocking development and testing work

Solution

Built a targeted migration approach that allows specific users and their associated data to be migrated from Production to UAT without replacing the entire environment.

Architecture

  • Databricks migration architecture: Integrates with Microsoft Dataverse APIs using FetchXML to retrieve only the required records for selected accounts/partners
  • Data extraction, transformation, and migration framework: Writes selected datasets into UAT Dataverse tables while maintaining required relationships and data integrity
  • Power Automate trigger: Integrated with Power Automate to provide a manual trigger mechanism — authorised users initiate migrations on demand via a simple button click
  • Selective scope: Users specify which accounts or partners' data they want to migrate, keeping UAT lean and relevant

Results

  • Eliminated the 1-day manual restore process — migrations now run on-demand in minutes
  • Reduced UAT environment data volume by 67% (30GB → 10GB) through selective migration
  • Zero disruption to downstream applications, reporting integrations, and synchronisations
  • Development and testing teams can get production-representative data whenever needed
