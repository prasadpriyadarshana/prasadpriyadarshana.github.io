Business Problem

The client required real-time analytics embedded directly into their portal, used by several Microsoft staff users, demanding sub-15-second data processing and rendering upon user actions.

  • Traditional Direct Query against relational databases was too slow for the latency requirements
  • Building custom analytics in React UI was estimated at 2–3 months of development effort
  • The client needed a production-ready solution urgently, with CI/CD deployment

Solution: Event-Driven Streaming Architecture

Technical Implementation

Databricks PySpark Structured Streaming

The Structured Streaming job was engineered with several critical design decisions:

  • Kafka endpoint integration: Connected to Azure Event Hubs via Kafka-compatible endpoint for maximum throughput and reliability
  • Instant trigger mode: Configured with continuous processing triggers rather than micro-batch intervals to minimise latency
  • JSON base64 unboxing: Portal payloads were base64-encoded nested JSON — the pipeline decodes, flattens and cleanses the structure on arrival
  • Precisely checkpointed: Exactly-once processing semantics via Structured Streaming checkpointing to prevent duplicate reads during cluster restarts
  • Schema enforcement: Strict schema applied at ingest to catch malformed events before they reach the Lakehouse

Power BI Direct Lake Mode

Output Delta tables written to Fabric Lakehouse are consumed by Power BI in Direct Lake mode — a Fabric-exclusive feature that reads Parquet files directly from the Lakehouse without import or DirectQuery overhead, delivering near-instant report loads even on large datasets.

CI/CD Deployment

The complete production solution was deployed with Git-based CI/CD pipelines, enabling controlled promotion from Dev → UAT → Production environments.

Results

  • End-to-end latency: under 15 seconds from user portal action to Power BI report update
  • 2–3 weeks delivery vs 2–3 months estimated for a custom React implementation
  • Zero duplicate processing via exactly-once Structured Streaming checkpointing
  • Full production deployment with Git CI/CD from day one
