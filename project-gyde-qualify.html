Project Overview

Designed and developed a secure usage analytics and partner reporting solution with Azure Data Lake Storage Gen2 (ADLS Gen2) as the primary data source. The client's web applications captured usage data through Google Analytics, periodically exported as CSV datasets delivered to dedicated ADLS Gen2 containers.

Architecture

Data Pipeline

  • Source: Google Analytics CSV exports delivered to ADLS Gen2 containers on a scheduled basis
  • Processing: Databricks jobs and PySpark notebooks for data ingestion, transformation, cleansing, and preparation
  • Reporting: Power BI data model and Power Query transformations designed for usage analytics reporting

Partner Security Model

A critical requirement was enabling external partners to view only their own usage data. The solution implemented:

  • Partner-level Row-Level Security (RLS) in Power BI based on partner email authentication
  • Each partner can securely access only their relevant usage data without direct access to the Google Analytics environment
  • A centralised and controlled reporting layer that maintains appropriate data access controls while enabling external sharing
