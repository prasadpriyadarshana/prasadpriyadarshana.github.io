Project Overview

Designed and implemented an ad-hoc reporting solution using Microsoft Fabric for the client's requirement to establish an end-to-end reporting platform within the Microsoft ecosystem. As Microsoft Dataverse was the primary data source and the client preferred not to use Fabric Link, the ingestion architecture was designed using Microsoft Fabric Dataflow Gen2.

Architecture

Design Rationale

Dataflow Gen2 was selected as the primary transformation layer to keep the solution simple, maintainable, and cost-effective while minimising unnecessary architectural complexity. This avoided the overhead of setting up Fabric Link or a separate Databricks cluster for what was a straightforward ingestion requirement.

Implementation

  • Ingestion: Fabric Dataflow Gen2 Dataverse connector extracts required tables
  • Storage: Microsoft Fabric Lakehouses as the centralised storage layer, following Medallion Architecture (Bronze → Silver → Gold)
  • Reporting: Power BI star-schema data model designed for efficient financial reporting and analytics
