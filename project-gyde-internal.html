Project Overview

Designed and developed a large-scale Power BI semantic model comprising 100+ tables and multiple interconnected mini semantic model structures, consolidating data across multiple business and analytical domains into a unified reporting platform for internal users.

Data Sources & Integrations

Azure Application Insights (10+ Applications)

  • Developed PySpark-based integrations using Service Principal authentication to connect to Application Insights endpoints
  • Retrieved JSON-based application telemetry for 10+ applications
  • Transformed raw telemetry into structured tabular datasets for analytics

Kademi Training Academy API

  • Built API-based ingestion pipelines to retrieve training and learning data from the Kademi platform
  • Applied cleansing, transformation, and standardisation using Databricks PySpark notebooks

Microsoft Dataverse (Extended Integration)

  • Extended the existing Dataverse integration by using Databricks and PySpark to retrieve Dataverse attributes that cannot be synchronised through Fabric Link — including JSON and attachment-related fields
  • Integrated additional data into the existing reporting model

REST APIs

  • Multiple custom REST API connectors built for supplementary data sources across the business

Architecture

  • Lakehouse structures and relationships designed and maintained across different reporting domains to support the unified semantic model
  • Microsoft Fabric Pipelines with scheduled execution for automated end-to-end data orchestration
  • Leveraged existing reporting datasets while integrating multiple new data sources through dedicated pipelines
