AI Portfolio Chat Agent

A serverless AI assistant embedded directly into my portfolio, powered by Google Gemini and Cloudflare Workers — enabling visitors to have real-time conversations about my skills, projects, and experience.

Prasad Priyadarshana
July 2026 · 5 min read

Project Overview

This project adds an intelligent conversational interface to my portfolio website. Instead of scrolling through sections to find information, visitors can simply ask questions in natural language and receive instant, contextually accurate responses.

The system uses a zero-cost serverless architecture — no databases, no servers to maintain, no monthly bills. It runs entirely on free tiers of Google Gemini API and Cloudflare Workers.

Why Build This?

  • Demonstrate AI skills: A working AI agent on a portfolio is a live proof of capability
  • Better UX: Visitors get instant answers instead of scrolling through pages
  • 24/7 availability: The agent answers questions even when I'm not available
  • Lead qualification: Recruiters and collaborators can explore my background conversationally

System Architecture

The architecture follows a simple three-tier pattern optimized for zero cost and zero maintenance:

LayerTechnologyPurpose
FrontendVanilla JavaScript + CSSSelf-contained chat widget injected into all pages
BackendCloudflare WorkersServerless proxy that hides API key and manages requests
AI ModelGoogle Gemini 3.5 FlashLLM inference with portfolio context as system prompt

Request Flow

  1. User types a question in the chat widget
  2. Frontend sends the message + conversation history to the Cloudflare Worker
  3. Worker prepends the system prompt (full portfolio context) and forwards to Gemini API
  4. Gemini generates a response based on the portfolio knowledge
  5. Worker returns the response to the frontend
  6. Chat widget displays the answer with typing animation

Technical Implementation

Frontend — Chat Widget

A self-contained JavaScript module that creates the entire chat UI dynamically:

  • Zero dependencies: Pure vanilla JS, no React/Vue/framework needed
  • Dedicated chat page: Opens in a new tab as a full-page experience (not a tiny floating panel)
  • Animated robot FAB: Custom SVG character with CSS float animation + tooltip on hover
  • Typing indicators: Bouncing dots while waiting for response
  • Suggestion chips: Pre-filled quick questions for first-time visitors (Work experience, Certifications, Projects, Tech skills, Contact)
  • Rich formatting: Bold highlights in green, proper bullet points, code blocks, and numbered lists
  • Mobile responsive: Full-height layout that works on all screen sizes

Backend — Cloudflare Worker

A serverless function that acts as an intelligent proxy:

  • API key protection: Gemini key stored as encrypted secret, never exposed to frontend
  • Full CV as system prompt: Injects the complete resume (work history, projects, skills, certifications, education) into every request
  • Conversation management: Maintains multi-turn chat context up to 20 messages
  • CORS handling: Proper cross-origin headers for any hosting domain
  • Graceful errors: Friendly fallback messages with contact info if API fails
export default {
  async fetch(request, env) {
    const { messages } = await request.json();

    // Build Gemini request with portfolio context
    const contents = [
      { role: 'user', parts: [{ text: SYSTEM_PROMPT }] },
      { role: 'model', parts: [{ text: 'Ready to help!' }] },
      ...messages.map(m => ({
        role: m.role === 'user' ? 'user' : 'model',
        parts: [{ text: m.content }]
      }))
    ];

    const response = await fetch(
      `${GEMINI_URL}?key=${env.GEMINI_API_KEY}`,
      { method: 'POST', body: JSON.stringify({ contents }) }
    );

    const data = await response.json();
    return new Response(JSON.stringify({ reply: data.candidates[0].content.parts[0].text }));
  }
};

Knowledge Layer — System Prompt

The AI's knowledge comes from Prasad's full CV embedded as a structured system prompt containing:

  • Professional summary and 4+ years of work history with metrics
  • All 9 certifications with issuing bodies
  • 7 key projects with technologies and impact numbers
  • Complete technical skills across programming, cloud, BI, and dev tools
  • Education (M.Sc. in progress + BSc)
  • Behavioral instructions (tone, length, boundaries)

The full CV fits within a single prompt (~3000 words), eliminating the need for a vector database or RAG pipeline while giving the AI comprehensive knowledge to answer detailed questions about any aspect of Prasad's background.

Key Features

1. Context-Aware Conversations

The agent maintains conversation history, so follow-up questions work naturally:

  • "What certifications does Prasad have?" → lists all 9
  • "Which ones are from Microsoft?" → correctly filters from previous answer

2. Graceful Boundaries

The agent honestly says "I don't know" when asked about things not in the portfolio data, and directs visitors to email for personal questions.

3. Zero-Cost Architecture

  • Gemini API free tier: 15 requests/minute, 1M tokens/day — no expiry
  • Cloudflare Workers free tier: 100,000 requests/day — no expiry
  • Total cost: $0/month permanently

4. Fast Response Times

  • Cloudflare Worker cold start: ~5ms (edge network)
  • Gemini inference: 1-3 seconds
  • Total latency: under 4 seconds for most queries

Lessons Learned

  • Full CV as context beats snippets: Giving the LLM the complete resume (~3000 words) lets it answer detailed follow-ups without hallucinating — and Gemini's 1M token window handles it effortlessly
  • Dedicated page beats floating widget: A full-page chat gives users room to read long responses and feels more like a real tool than a cramped popup
  • Edge computing matters: Cloudflare Workers respond from the nearest edge node, cutting latency significantly vs centralized servers
  • Free tiers are production-ready: For portfolio-level traffic (10-50 requests/day), free tiers are genuinely sufficient
  • Rich formatting makes AI feel polished: Rendering bold highlights, bullet points, and code blocks in responses transforms the experience from "raw text dump" to "professional assistant"
