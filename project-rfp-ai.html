Project Overview

Designed and developed the data engineering architecture and end-to-end data preparation pipeline supporting an AI-powered RFP platform. The goal was to convert complex business data into structured, AI-ready datasets that enable contextual and localised AI recommendations.

Architecture

Data Ingestion

  • Integrated and transformed data from Microsoft Dataverse as the primary source system
  • Designed the data processing layer using Databricks, PySpark, and Spark SQL within Microsoft Fabric Lakehouse

Data Transformation Framework

  • Developed data models and transformation frameworks to convert complex business data into structured, AI-ready datasets
  • Incorporated business rules, prioritisation, ranking, and multi-language data to support contextual and localised AI recommendations
  • Moved complex data processing, transformation, and ranking workloads into the data engineering layer rather than processing at application runtime — reducing application-side infrastructure requirements and improving AI response times

Cosmos DB Serving Layer

  • Architected and implemented Azure Cosmos DB (NoSQL) as the downstream serving layer
  • Designed JSON-based data structures optimised for application and AI consumption
  • Pre-processed, ranked, multilingual, and application-ready datasets allow the development team to consume data efficiently without runtime processing overhead

Key Design Decisions

  • Pre-processing over runtime processing: Heavy ranking and business logic applied at the data layer, not the application layer — reducing AI inference costs and improving response latency
  • Multi-language support: Data prepared with localisation in mind, supporting the platform's international RFP requirements
  • NoSQL for AI serving: Cosmos DB's JSON-native model and global distribution align with the AI application's consumption patterns better than a relational serving layer
